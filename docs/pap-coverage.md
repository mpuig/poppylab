# PAP 0.3 coverage matrix: Poppy, Juniper and Lantern

This describes the current implementation against **PAP draft 0.3** and **Operations v2**. **It does not certify conformance**: it is a map of capabilities, limits and evidence, not an inventory of every MUST and SHOULD. The draft changes often, so the normative review uses the text pinned in `spec/` (retrieved on 3 November 2026; `pnpm spec:drift` reports later changes). Details in [PAP 0.3](pap-03.md).

**Poppy** is the Personal Agent. **Juniper Market** and **Lantern Noodle Bar** are fictional Companies that share one PAP gateway (`packages/pap-company`) with their own scopes, contracts and business. They run locally (`http://juniper.localhost:4100`, `http://noodles.localhost:4200`) and publicly (`juniper.poppylab.dev`, `noodles.poppylab.dev`). 0.1 and 0.2 are no longer accepted.

Legend: **I** implemented (within the stated limits) · **P** partial · **N** not implemented · **—** not applicable. Evidence: **A** automated tests · **V** documented live check · **C** code inspection only.

Current suite: **391 tests**; `pnpm scenarios` groups them by topic (`pap-0.3`, `noodles`, `permissions`, `revisions`, `operations`, `recovery`, `mcp`, `nonce`, `authority`).

## 6. Security and project limits

- Secrets (refresh and access tokens, Session JWTs, keys, codes and PKCE verifiers) stay out of the model context and the traces. Browser API keys live only for the request.
- **Public deployment:** each visitor has their own agent state in a Durable Object, sealed at rest with `POPPY_STATE_KEY`, and their own copy of each Company's fictional customers. Budgets per visitor, IP and globally; no client may hold more than a fifth of a Company's shared caps.
- Storage is single-writer (encrypted vaults on Node, one Durable Object per Company on Workers); there is no distributed coordination.
- **External demos:** the PAP Sandbox publishes 0.3 discovery but still requires the 0.2 Session Token; Cliffside Retail follows the earlier 0.3 text (`pap_dlg`), which Poppy falls back to; Print with Poppy's sandbox accepts registered agents only. See [community demos](community-demos.md).
- There has been no independent security review and no official conformance check.
